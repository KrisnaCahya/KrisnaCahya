> ⚠️ *Snake requires a GitHub Actions workflow — see setup instructions below.*

</div>

<details>
<summary><b>🐍 Setup Snake Animation (click to expand)</b></summary>
<br>

Buat file `.github/workflows/snake.yml` di repo ini:

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: KrisnaCahya
          outputs: dist/snake.svg
      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

Setelah itu jalankan workflow sekali manual dari tab Actions.
